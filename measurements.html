How to read the measurements

Hardware and repeatability
One H200 per run on a shared eight-GPU host. Up to eight workers use separate GPUs and CPU affinity sets, but share host memory and storage; NUMA locality varies. Each result is one measured run after a separate-process warm-up. Software, precision, compilation, and offloading differ.
Frames and output size
Frames count completed output across chunks. Dimensions describe the output region after cropping or paste-back, excluding comparison panels. A lip-editing canvas can be larger than the internal synthesized crop.
Pre, Gen, and Post
Stages follow each implementation. Gen usually covers denoising for dense diffusion or motion prediction plus rendering for appearance reuse. Dense-diffusion VAE decoding is generally in Post. Supplied training, tracking, or features are excluded where accepted as prerequisites.
Load and Process
Load is model initialization. Process includes loading, stages, and additional overhead; it is not their sum or time to first frame. Ditto and TalkLikeYou have overlapping threaded stages. SyncTalk includes an extra evaluation pass in Process and memory, outside the three inference phases.
Memory
NVML samples the process and descendants every 100 ms over the entire process, including loading and auxiliary stages. This sampled peak can miss brief allocations and is not a minimum device-capacity requirement. Separate PyTorch allocated/reserved counters are included in the downloads; some exceed the sampled NVML peak.
Scope
These short demo runs do not measure matched visual quality, sustained service, streaming startup, or long-session drift. StyleAvatar uses two frames; LeapTalk uses one chunk; TaoMate uses one window. Paper-reported performance remains attached to the literature records.
