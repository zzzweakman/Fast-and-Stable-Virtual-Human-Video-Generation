51 configurations. 51 methods. One H200 per configuration.

The tables include configurations with recorded first-call loading and all reported timing and memory fields. Three complete warm-ups precede three measured calls in the same interpreter: 306 included calls.

Ten configurations retain audited models; 41 reload models each call. Inputs, settings and residency differ, so these results describe implementations under their stated workloads.

Load₁ reports the first invocation. It comes from warmup_01, before any previous full warm-up. Pre, Gen, Post and Call summarize the three later measured calls. Load₁ cannot be added to those means to obtain a measured total.

Call and suite are different clocks. Call reports the measured request. Suite total includes setup, all three warm-ups, all three measured calls, output checks and shutdown. Neither is time to first frame.

Main tables report warmed memory. Each value is the maximum sampled peak over the three measured calls and includes loading, pre-processing, generation and output processing.

How to read the measurements

Repeatability and hardware
Three full warm-ups, then three measured calls per configuration, using one H200 across three nodes. Every call repeats its selected clip and writes fresh output. Four CPU-affinity identifiers and numerical-library thread limits of four do not imply four independent physical cores. Host memory, storage and caches remain shared.
Selection and archive
The displayed 51 configurations have all table metrics recorded. Five configurations without an initial loading interval are excluded. The original 56-configuration archive and all 336 calls remain available.
Output workload
Dimensions show generated regions or paste-back canvases, excluding comparison panels. Internal face crops may be smaller. Talker-T2AV resets seed 42 at the generation boundary and produces 136 frames in all six calls. No common seed is imposed across methods.
Initial loading and warmed stages
Load₁ is one observation from the first recorded invocation, warmup_01; disk caches may already be populated. Pre, Gen and Post use implementation-specific synchronized event boundaries. VAE decoding is generally in Post for dense diffusion; controller plus renderer are generally in Gen for appearance reuse. Warmed Call includes any loading performed in that call, native validation and unclassified overhead. Ditto and Talk Like You overlap phases, so stage sums are not elapsed time. SyncTalk has native validation inside Call, outside Pre/Gen/Post. Generic output QA is outside Call.
Suite total
The complete 3+3 process includes startup/import, setup, all six calls, output QA and shutdown. This replaces the old fresh-process interpretation and must not be divided by six to estimate measured-call latency. The first measured call is already after three warm-ups.
Memory measurement
Own-process/worker NVML samples are collected approximately every 100 ms. Warm peak is the maximum of the three measured-window peaks after warm-up. Sampling may miss brief allocations; framework counters do not cover every CUDA allocator.
Model and input state
Same interpreter does not mean every model stays resident. Ten included configurations retain model objects; 41 reload each call. Precomputed tracking, features, masks and subject-trained assets remain prerequisites where the demo expects them. LAM performs fresh tracking.
Metadata and evidence
No new attention capture accompanies these timed runs. Labels for 44 included implementations are historical execution observations; seven use source/configuration inspections. Package versions and Git heads are post-run inventories. Archived launch records supplement six configurations; unrecorded sampler and decoder defaults remain unspecified.
Archived outputs and paper figures
The workbook is supported by JSON reports, iteration records, phase events, NVML samples and output videos. The 306 included call times match the archived records, and each configuration's first measured primary output was decoded to check frame count and canvas dimensions. The current 54-page survey uses schematic portraits and representation diagrams, a radial taxonomy, and a stage-cost figure derived entirely from first-call timings. Earlier output crops and their provenance remain archived.
Interpretation limits
Initial loads, measured means, sample SDs, memory maxima, phase unions and frame sequences were reconciled with the corresponding records. Adapter source, model weights and complete environments were not included in the archive. Output checks do not measure perceptual quality. Different workloads and repeated short clips do not establish a controlled ranking, TTFF, sustained service or long-session stability.
