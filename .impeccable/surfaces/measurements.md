# Measurements

Mode: Read.

Readers: researchers inspecting the cost of running an open-source virtual-human implementation.

Task: find a method, read its output length/resolution and stage timings, understand the measurement boundary, and download the data.

This page extends the existing research-index visual system: Manrope, forest text and controls, neutral reading surfaces, ruled tables. It has no performance ranking or decorative chart. Native table semantics, a fixed first column, keyboard-focusable horizontal scrolling, and explicit pending text preserve the same task on mobile. The tables render without JavaScript.

Sources: author-supplied 15 October single-H200 measurements. The public 16 October release includes 44 results. MuseTalk, VideoReTalking, and three Soul methods have blank numerical fields across the page and downloads. The existing literature catalogue, annual totals, source-reported values, and archived releases retain their scope.
