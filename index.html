    Five recurring patterns for stability

    A common vocabulary across the survey.

    Persistent identity anchors

    Keep a reference image, appearance representation, or identity asset available throughout generation. It can constrain identity drift while also limiting intended changes.

    Bounded multiscale memory

    Combine recent detail with longer-term context under a finite state budget. Memory size and retention policy must be evaluated alongside visual consistency.

    Position re-indexing

    Adjust temporal position indices as the generation window advances, helping a model operate within its trained positional range during extended generation.

    Self-history training

    Train with model-generated histories to address the difference between clean training context and imperfect inference-time context.

    Motion inheritance

    Carry motion information across generation boundaries to support continuity. The representation and hand-off policy influence how errors propagate.
